# 🍰 小日嚐烘焙 (Daily Bakery) - 精選甜點線上商店

> 一間溫暖且注重細節的手作甜點烘焙線上展示平台，運用現代前端技術呈現優雅、直覺且具備響應式體驗的購物空間。

🔗 **線上展示網址 (Live Demo)**: [點此立即造訪小日嚐烘焙網站](https://1121703.github.io/Daily-Bakery/) *(請在開啟 GitHub Pages 後替換)*

## 📌 專案概述 (Project Overview)

本專案為 **Web 程式設計** 課程之期中專題實作，旨在為自創品牌「小日嚐烘焙」設計兼具品牌美感與實用機能的線上甜點展示與訂購網站。整體視覺以大地暖色系與柔和奶油色調為基底，結合高質感甜點圖像與流暢的排版結構，提供訪客沈浸式的甜點瀏覽體驗。

---

## ✨ 核心功能與頁面規劃 (Features & Pages)

1. **品牌首頁 (Home - `index.html`)**：
   - 品牌理念與精緻形象輪播展示。
   - 快速導覽與最新主打甜點推薦。
2. **商品選購專區 (Shop - `shop.html`)**：
   - 條理分明的甜點陳列（千層蛋糕、起司乳酪、生乳捲、精選餅乾禮盒等）。
   - 圖文並茂的商品卡片與即時選購介面。
3. **品牌故事與創作理念 (Creation - `creation.html`)**：
   - 傳達「用剛出爐的香氣，溫暖生活日常」的烘焙初衷。
4. **烘焙日曆與出爐排程 (Calendar - `calender.html`)**：
   - 清晰呈現每日新鮮出爐的品項與預約取貨時間。
5. **互動購物車機制 (Cart - `cart.js`)**：
   - 透過 JavaScript 實作購物清單動態計算與使用者互動操作。

---

## 🛠️ 技術堆疊 (Tech Stack)

- **前端標記語言**：HTML5（語意化標籤架構）
- **樣式與版面配置**：CSS3（Flexbox / CSS Grid 佈局、響應式排版 RWD、自定義過渡動態）
- **互動邏輯與腳本**：JavaScript（DOM 操作、事件監聽、購物清單動態渲染）
- **版本控制與部署**：Git / GitHub / GitHub Pages 靜態網站代管
